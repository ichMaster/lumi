### LUMI-216: The streamed turn (#216)

**Status:** completed · **Commit:** 27e85b3

`POST /v1/turn/stream` → SSE `delta`/`think`, then exactly one `done` (the `/v1/turn` payload, the emotion
validated on completion) or `error`. A turn registry: one runner thread per turn holds the lock to the end;
outcomes kept by `turn_id` (last 32); a known id on either route returns the stored outcome — never a second
`core.reply`. `GET /v1/state` adds `stream_enabled`. Additive to API v1.

**Validation:** 12 new tests (incl. a client disconnect mid-turn); contract extended; ARCHITECTURE updated.

## Architecture impact

- API v1 grows additively: the SSE stream route, `turn_id` idempotency on both turn routes, `stream_enabled`
  in the state (ARCHITECTURE §Contracts, the contract test).
- The Gemini loops gain a bounded "empty answer → one forced final round" retry, visible as an `empty`
  round in the cache log.

## Found, for the review

- **A forced stop waits out a thinking silence** — the SSE generator blocks on its queue with no timeout, so
  even a double Ctrl+C can't cancel until the next event (measured 7 s); the owner chose to skip it for now.
- **Shutdown while a turn runs** — `end_session` (the summary) runs on the main thread while the turn's
  runner may still be inside `core.reply`.
