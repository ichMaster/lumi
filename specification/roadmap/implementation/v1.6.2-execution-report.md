**Status:** completed · **Commit:** ddc2f07

### LUMI-201: Streaming TTS output + barge-in (#201)

**Status:** completed · **Commit:** e0df29e

`voice/stream_tts.py`: `ElevenLabsStreamTTS` (the stream endpoint, `pcm_24000`, injectable opener,
`MockStreamTTS`), the lossless `SpeakerBuffer` (pull-exactly — the garbled-voice fix), and the
`SpeechPipeline`: deltas → a defensive `StreamTagFilter` → `SentenceAssembler` →
`clean_sentence` + the `speakable` Latin-vs-Cyrillic gate → one synth per sentence into the
buffer. **Barge-in:** `interrupt()` clears the buffer + the queue and epoch-aborts the in-flight
sentence's remaining chunks — playback only, never the committed turn; idempotent. The guards
moved from the probes; `chain_probe` re-exports them.

**Validation:** 6 tests (tests/unit/test_stream_tts.py) · full suite 1664 · ruff.

### LUMI-202: /mode-set voice — the in-TUI live loop (#202)

**Status:** completed · **Commit:** a8c1b8b

`voice/live.py`: the `VoiceLoop` (a non-empty interim while she is audible → interrupt; committed
utterances via the tracker; `on_utterance` non-blocking so the pump never goes deaf; the synth
pump) + `open_audio` sounddevice glue. TUI: `/mode-set text|voice` + `LUMI_MODE_SET` (default
text), `_start/_stop_voice_mode` (key checks, idempotent teardown), spoken turns serialized on the

renders in the TUI AND speaks sentence-by-sentence; typed input + slash commands keep working;
every failure (keys/WS/TTS/mic/socket-close) degrades to text with a readable line; `mode:voice`
in the status bar. `.env.example` + VOICE_MODE.md operator notes (v1.6.2 marked SHIPPED).

**Validation:** 5 tests (tests/unit/test_voice_live.py — barge-in decisions,
one-turn-per-utterance, the end-to-end spoken turn on a fake Deepgram socket + mock TTS, the
