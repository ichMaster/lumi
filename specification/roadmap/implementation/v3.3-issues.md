## v3.3 — The room's turn: fast, allowed to pass, retractable

### LUMI-289 — Passing: an empty reply or Gemini's «…» is a `pass`; the `register` checked

**Description:**
In the room an empty reply is silence, not an error: `{"outcome": "pass", "reply": ""}` with a 200, nothing stored as
her line. In his channel an empty reply stays an error, unchanged. The files are `core/space.py` and `server/app.py`.

**What needs to be done:**
- `AgoraSpace._answer`:
  - an `EmotionError` from the gate (an empty or missing reply) becomes a pass;
  - so does Gemini's placeholder for a blocked or empty candidate (`_GEMINI_BLOCKED_STATE`'s `"…"`, also `"..."`),
    carried from v3.1 review #8;
  - both join v3.2's name guard on one pass path: no line stored, the outcome kept for a retry, a log line saying
    why (never the text).
- **The register:** a room turn's `register` is `"voice"` (missing → `"voice"`, the room's default: no inner voice,
  the room's model, no tools); any other value → `422`. On his channel `register` stays ignored.
- His channel: `Core.reply` and `validate` are untouched; an empty reply there is still an error (pinned).

**Dependencies:** None

**Expected result:**
Whatever the room's model leaves empty or blocked, the room hears silence and her memory of the room holds nothing.

**Acceptance criteria:**
- [ ] An empty reply, a whitespace reply, a missing `reply`, `"…"` and `"..."` → `200 {outcome: "pass", reply: "",
  turn_id, stats}`; nothing stored as her line; a retry → the same pass, no second call.
- [ ] `register: "voice"` or none → the room's path; another value → `422`.
- [ ] His channel: an empty reply is still an error (the existing contract test + one more).
- [ ] **Tests:** unit (core + server) with a fake room model.
- [ ] **Gates:** `ruff`, `pytest`.

### LUMI-290 — Retracting: `POST /v1/turn/{turn_id}/retract` — always a 200, idempotent, never his

**Description:**
When matrix-agora's rules drop her reply (or the bridge timed out, or its send failed), the reply leaves the room's
session and its vectors, so she never remembers saying what the room never saw. It is always a 200 (R8). The files
are `core/space.py` (`AgoraSpace.retract`) and `server/app.py` (the route).

**What needs to be done:**
- `AgoraSpace.retract(turn_id) -> bool`, atomic with the store-or-drop step (v3.1 review #1's lock):
  - a running turn → marked; its reply is dropped when it ends → `True`;
  - a stored reply → removed (line, vector, kept outcome) → `True`;
  - otherwise (a pass, a timeout, never received, already retracted) → `False`.

  The trigger line stays: the room did say it. A retracted `turn_id` is remembered (bounded), so a later retry
  answers a pass, never a second reply.
- `POST /v1/turn/{turn_id}/retract` exists only while the space is on. The `turn_id` is URL-decoded, `$` arriving
  as `%24`.
  - With the room's token: `200 {retracted: true|false}`, idempotent.
  - With the owner's token: `403`. It is the room's route; his turns are never retractable (the ROADMAP's test).
  - Without a token: `401`.
- The route-set contract: the space on adds `POST /v1/observe` and `POST /v1/turn/{turn_id}/retract`.

**Dependencies:** LUMI-289

**Expected result:**
A reply the room never showed is gone from her memory of it; any retract answers 200.

**Acceptance criteria:**
- [ ] A stored reply → `{retracted: true}`; the line and its vector gone (recall never finds it); the trigger stays.
- [ ] Nothing stored (a pass, a timeout, an unknown id), or a second retract → `200 {retracted: false}`.
- [ ] A retract during a running turn → `{retracted: true}` and the reply is dropped when the turn ends.
- [ ] A retried turn after a retract → a pass, no second reply.
- [ ] The owner's token → `403`; no token → `401`; the space off → `404`.
- [ ] **Tests:** unit (core + server), the interleaving driven explicitly.
- [ ] **Contract:** the route set (`test_server_api_contract.py`); the `retract` examples served as written
  (`test_agora_server_contract.py`); ARCHITECTURE §Contracts in line.
- [ ] **Gates:** `ruff`, `pytest`.

### LUMI-291 — The hourly cap: `agora.max_turns_per_hour` → `429`

**Description:**
At most `agora.max_turns_per_hour` room turns call the model in any rolling hour (matrix-agora's R5, 20 by default);
past it a room turn is `429`, silence in the room. It lives in `core/space.py` and `server/app.py`.

**What needs to be done:**
- `AgoraSpace(max_turns_per_hour=…)`, a rolling window of the model calls' start times (injected monotonic clock).
  - A retry answered from a kept or stored outcome never counts.
  - `0` turns the cap off.
- `SpaceCapped` → the server's `429` "the room's hourly cap is reached".
- The server wires `cfg.agora_max_turns_per_hour`.

**Dependencies:** LUMI-289

**Expected result:**
A chatty room can't run up her model bill; the bridge hears silence and never retries.

**Acceptance criteria:**
- [ ] The 21st model call within an hour → `429`; an hour later → served again; retries never count; `0` → no cap.
- [ ] **Tests:** unit with an injected clock + the server.
- [ ] **Gates:** `ruff`, `pytest`.
