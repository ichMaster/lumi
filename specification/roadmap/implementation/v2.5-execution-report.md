## Architecture impact

- The brain's clock and bus are host-neutral modules (`core/scheduler.py`, `state/bus.py`).
- In server mode the server hosts her time and the file bus — the single outbox writer; the Telegram daemons
  run beside it on the same data root.
- API v1 grows additively: the `message` event, SSE ids + `Last-Event-ID` + the in-memory replay (50 events,
  per boot), a client request waiting for the server's own act instead of `409`.

## Found, for the review

- The replay buffer is per boot and in memory by design (owner's choice) — a server restart starts empty.
- A `send_image` photo isn't a `message` (the API never carries images) — a connected client doesn't see it;
  Telegram does.
