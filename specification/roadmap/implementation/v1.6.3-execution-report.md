## Detailed Results

### LUMI-203: The first-clause cut (#203)

**Status:** completed · **Commit:** 1b00e36

`FirstClauseAssembler`: until the turn's first chunk is emitted, a clause boundary (`, ; :` +
whitespace, ≥3 words before it) or the first N complete words
(`LUMI_VOICE_FIRST_CLAUSE_WORDS`, default 8) also flushes — the probes measured ~0.3–0.65 s of
felt latency in the full-first-sentence wait. Later chunks stay whole sentences; never mid-word;
a sentence arriving complete in one delta speaks whole; `finish_turn()` re-arms per turn; `0` →
byte-identical splitting (pinned). Spoken stream only.

**Validation:** 5 new tests · full suite 1692 · ruff.

### LUMI-204: Emotion-colored delivery (#204)

**Status:** completed · **Commit:** 58fd3e8

`SpeechPipeline(emotion_supplier=…)` reads the current validated emotion per sentence and passes
it into `tts.stream(emotion=…)` — `voice_settings_for` (the shared v0.14 mechanism) maps it. The
TUI supplies `Core.last_emotion`: the previous turn's state colors the live stream, the new state
takes over per-sentence once validated. Supplier absent/None/raising → the neutral middle.

**Validation:** 2 new tests (per-sentence handover, degrade paths) · full suite 1694 · ruff.

### LUMI-205: Deepgram WS resilience (#205)

**Status:** completed · **Commit:** 8ef260a

`VoiceLoop.pump_events_resilient`: a dropped/closed socket heals in place — up to
`LUMI_VOICE_RECONNECT` (default 3) reopen attempts with exponential backoff, a fresh
`UtteranceTracker` per reconnect, the budget resets per outage; returns only when exhausted → the
unchanged readable degrade to text. `DeepgramStream.reopen()` heals the SAME object (the mic
closure survives); `send_pcm` drops frames into a dead socket silently. Notes: «voice:
reconnecting N/M…» / «voice: reconnected».

**Validation:** 2 new tests (the scripted fail-then-succeed outage end-to-end; the dead-socket
sender guard) · full suite 1696 · ruff.

### LUMI-206: Voice observability (#206)

**Status:** completed · **Commit:** 13f466a

Three stamps per spoken turn (commit + endpoint gap from the mic-peak stamp; the first reply
delta; the first audio chunk via `mark_turn`/`on_first_audio`) → one dim line per turn
(`voice: endpoint 0.7s · llm first 0.9s · tts first 0.3s = 1.2s`) + a `/latency` voice section
(stage medians, present only when spoken turns exist). `core/usage.py` prices Gemini
(3.1-pro $2/$12 · 3.5-flash $1.50/$9 · 2.5-flash $0.30/$2.50 · flash-lite $0.10/$0.40 + family
fallbacks) — before this every gemini call (the whole voice mode) was estimated at the $5/$25
opus default.

**Validation:** 4 new tests · full suite 1700 · ruff.
