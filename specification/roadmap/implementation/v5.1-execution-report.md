## Deviations

- **The worktrees started from `main`, not from `v5-dev`.** Both wave-1 forks noticed it and moved onto `v5-dev`
  themselves. The skill now tells a fork to reset onto the branch tip first, and the merge checks each fork's base
  (390951c). `.claude/worktrees/` is ignored.
- **The concept's `turn_id`** is the turn's `turn_ts`, since the core has no turn id.
- **New origin.** The brain's idle think and nudge, which run outside the schedule, have the origin `idle`.
- **The box's name** in the shell is the address the page was opened at; the container can't read the host's name.

## Found, not changed (for the review)

- **The server never trims its logs.** `core/logtrim.py` runs only in the in-process TUI, so on the box
  `cache-log.jsonl` and the two new ledgers grow untrimmed. The panel's reader copes (it reads a ledger from its
  end), but the files keep growing.
- **The unit prices** in `core/pricing.yaml` are list prices the fork knew, not checked against the providers' pages.
