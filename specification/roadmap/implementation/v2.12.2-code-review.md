## Findings

### 1 — 🟡 LOW — the theme is an unchecked folder name

In `desktop/faces.py` `FacePicker.pick`, the only check on `theme` is `(faces_dir / theme).is_dir()`, so `theme=..`
or `theme=../..` passes it.

**Scenario:** a crafted `/face?theme=../..&emotion=sad` request.
1. `resolve_variants` lists `faces/../../sad/*.png`.
2. The final `relative_to(faces_dir)` turns that into "no picture" (404), so nothing is served.
3. But the picker has already listed folders outside the pack and remembers an outside path as its last pick.

The request needs the launch key, so only the page itself can send it.

**Fix:** a theme must be a plain slug (`[A-Za-z0-9][A-Za-z0-9_-]*`); anything else counts as no theme, and the default
chain applies.

### 2 — 🟡 LOW — thoughts missed while offline aren't new

In `desktop/ui/app.js` `onThought`, `unread: !data.replay` treats every replayed thought as history. After a
reconnect, though, the server replays only what this listener missed (`Last-Event-ID`).

**Scenario:** the server is down for a minute while she thinks twice, then comes back. The strip lists both thoughts,
but "N new" stays at 0.

**Fix:** a replayed thought is unread while the page collects what it missed after a reconnect
(`st.collectMissed`), and history only on the first connect.

### 3 — 🟡 LOW — the app's log never stops growing

`scripts/make_mac_app.py` `launcher()` runs `exec uv run … >>"$HOME/Library/Logs/Lili.log" 2>&1` on every launch with
no limit.

**Fix:** before appending, the launcher moves a log over 1 MB to `Lili.log.1` (one generation kept).

## What's solid

- **No face reaches the server.**
  - `/face` and `/faces/` are answered by the proxy from the local pack, and `FORWARDED` is unchanged (contract-pinned).
  - `/faces/` serves PNGs only, under the pack, through the same path check as the page.
- **The portrait never flickers back to an old state.** A sequence number drops a stale `/face` answer, the same
  `src` never swaps, and the image swaps only once the hidden layer has loaded.
- **Thoughts never enter the chat.** A static test pins that `onThought` calls no row builder.
- **The emotion stays the model's.** The page only renders what the server validated (`emotion` / `intensity` from
  `done` and the pushes). The caption and the emoji map are total over the enum, with `calm` for anything unknown.
