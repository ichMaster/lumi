# v4.8 — Issues

Issues for phase **v4.8 — English everywhere: the interface, the code comments and the documents** (version **v4 —
The window**), derived from the Tasks and DoD in [ROADMAP.md](../../ROADMAP.md) §v4.8 and the contracts in
[ARCHITECTURE.md](../../ARCHITECTURE.md). This file covers one phase; ids continue from the previous phase (LUMI-334 →
**LUMI-335…339**).

The phase makes everything a person reads that is not her own words English: the slash commands' answers, the
terminal client, the CLI, the viewer, the server's and the window's status strings, the code comments and docstrings,
and the documentation. It first pins her prompt (every model-facing text) so the cleanup provably leaves her
behaviour alone. The open questions of §v4.8 are taken as proposed (the owner started `/ship-phase 4.8` with them
standing): the tools' own result phrases stay as model-facing data, and her name stays «Лілі» in documents and
comments while the interface writes "Lili".
