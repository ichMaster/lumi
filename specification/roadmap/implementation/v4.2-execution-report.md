## Detailed Results

### LUMI-305: The gallery logic

**Status:** completed
**Commit:** 5c93ddf
**Files changed:**
- `core/gallery.py` (added): `list_pictures` and `thumbnail`.
  - Pictures are typed by their magic bytes, the same rule as `core/browse.py`.
  - The order is newest first, `(-mtime_ns, path)`, paged by an opaque base64url cursor; a folder filter matches one
    folder exactly (`""` is the root).
  - The caps: 10,000 files scanned, 100 per page, 50 megapixels per source picture (read from the header before
    decoding).
  - A thumbnail is a 320 px JPEG cached as `sha256(path)[:32]-mtime_ns.jpg`, written atomically; the path's older
    thumbnails are dropped. A cache folder inside the sandbox is refused.
- `tests/unit/test_gallery.py` (added, 24 tests): Pillow fixtures, paging, the cursor, the caps, the cache, and the
  sandbox's fingerprint unchanged after every call.

**Validation:**
- [x] Unit tests: pass.
- [x] Lint (ruff): pass (the import order was fixed by `ruff --fix`).
- [x] Acceptance criteria: all pass.
