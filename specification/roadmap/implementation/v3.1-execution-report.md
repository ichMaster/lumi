## Departures from the plan (for CR3)

- **The settings are `agora.*`, not `spaces.agora.*`** (LUMI-278). The v2.9 schema, its example files,
  `lumi-cli config set` and the admin editor all take two-level keys. ROADMAP, ARCHITECTURE, AGORA_SPACE.md and the
  contract's text were renamed with it.
- **The room's usage is per call, not per session** (LUMI-280). Each room call is a `cache-log.jsonl` row with
  `kind: "agora"` (the ledger the admin panel's tokens and cost read). His per-session `usage-ledger.jsonl` gets no
  room row, so the panel's "sessions per day" stay his. `UsageRecord` is unchanged.
- **The contract changed twice, still API v1** (LUMI-281): `observe.about` and the `422` row now state the speaker
  rule (Q3); the `401` example's detail is the server's real one, `"unauthorized"` (it said "the client token is
  missing or wrong"). matrix-agora re-copies the file (`cmp`).
- **A room's session is the one of her local day of the line's own `ts`** (`agora-YYYY-MM-DD`, `…-2` past 1000
  lines), so a late line lands in its own day.
- **`register` is `register_` in Python** (pydantic's `BaseModel` has a `register`); `"register"` on the wire.
- **The integration test is `tests/integration/test_agora_beside_his_turn.py`** (the unit test holds the planned basename).

### LUMI-280 — the space turn (#280)

`AgoraSpace.observe` (idempotent, embedded, no model call) and `AgoraSpace.turn`:
- the trigger is stored from the turn when observe hasn't brought it (R1);
- the prompt is the canon, a short framing and the window by `ts`, with the trigger last, as one quoted transcript;
- one call to the room's own Gemini client (thinking off, its deadline = `agora.timeout_s`), then the v0.3 gate;
- her reply is stored under the trigger's `turn_id`; a retry returns the kept or stored outcome, never a second call;
- `SpaceBusy` → 409; a timeout or an abandoned turn (`SpaceTimeout`) stores no reply.

A `Core` built beside it keeps its `last_emotion`, `last_stats` and `totals`.
