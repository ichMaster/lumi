with the default handler restored, which killed the server (−15) before `main()`'s `finally` — the session close
never ran on a `systemctl stop`; now SIGTERM = Ctrl+C (a real-process test fails without the fix). **Ports, at the

stops, `/v1/events` answers 503 — a reconnect no longer reads the stop as "back" (`test_tui_pushes` was flaky,
1 in ~5; 25 runs green after).
