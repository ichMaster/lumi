- **One pass path.** A pass covers an empty or missing reply (the gate's `EmotionError`), Gemini's blocked placeholder
  `"…"` (also `"..."`, `"…."`; v3.1 review #8) and v3.2's name guard. The log names the reason, never the text. A
  reply with an ellipsis inside («Хм… туман.») is an ordinary reply.
- **`retract` is the room's own route.** The owner's token gets `403`. This is how the ROADMAP's test "the owner
  token's retract on his channel `403`" is read; it narrows v3.1's "the owner's token keeps its full reach" for this
  one route.
- **A retracted id is remembered** (bounded). A turn retried after its retract answers a pass, never a second reply;
  this covers matrix-agora's retract after its own timeout when the turn reaches Lumi late.
- **The cap** counts the room's model calls (not requests) over a rolling hour. A retry answered from a kept or
  stored outcome never counts, and `0` turns the cap off. The room's line is still stored when the cap answers 429.
- **The contract file is unchanged** in v3.3. `turn_pass`, `retract`, `429` and the details were already in it, and
  every example is now served as written.

## Detailed Results

### LUMI-289 — passing (#289)

`AgoraSpace._answer` maps the gate's `EmotionError` to `state=None`, then `_pass_reason(state)` returns `empty` /
`blocked` / `names the owner` / `None`. A pass stores nothing as her line, keeps the outcome, and logs why. The
server checks `register` (`voice` or none, else 422). His channel is pinned: an empty reply there is still a 500.

### LUMI-290 — retracting (#290)

- `AgoraSpace.retract(turn_id)` runs under the store-or-drop lock:
  - a running turn → marked, its reply dropped at its end → `True`;
  - a stored reply → removed (line, vector, kept outcome) → `True`;
  - otherwise `False`.

  The trigger stays.
- The route `POST /v1/turn/{turn_id}/retract` (only while the space is on):
  - the room's token → `200 {retracted}`;
  - the owner's token → `403`;
  - no token → `401`;
  - the space off → `404`.
- The route set and the `retract` examples are pinned.

### LUMI-291 — the hourly cap (#291)

`SpaceCapped` comes from `_take_a_call()` before the prompt is built; the server maps it to `429` "the room's hourly cap
is reached" and wires `cfg.agora_max_turns_per_hour` (20).
