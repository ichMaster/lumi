# v3.1 — Issues

Issues for phase **v3.1 — The channel: the room's store, `observe`, its token, its own turn path** (version **v3 —
Agora: the room as a channel of her own**), derived from the Tasks and DoD in [ROADMAP.md](../../ROADMAP.md) §v3.1, the
contracts in [ARCHITECTURE.md](../../ARCHITECTURE.md) (§Spaces, §Contracts) and the agora space API v1
([`docs/agora-space-api.json`](../../../docs/agora-space-api.json)). This file covers one phase; ids continue from the
previous phase (LUMI-277 → **LUMI-278…283**).

v3.1 gives matrix-agora's bridge a channel of its own in Lumi: the room's lines are heard (`observe`) and kept in a
store of their own, keyed by the space; a room turn runs on a separate **space turn** (its own prompt, its own Gemini
2.5 Flash client, its own lock), never `Core.reply` and never the core lock; a scoped room token reaches only the
room's routes. Nothing of the room reaches the owner's session, Telegram, desktop, events, state, totals or idle
clock. Her memory of the room in his talk, the room rule, the name guard and the sentinel are **v3.2**; `pass`,
`retract` and the hourly cap are **v3.3**. Step 3 of the synchronization with matrix-agora (AGORA_SPACE.md
§Synchronization): `/ship-phase v3.1` → `v3.1.0`, then the deploy to dev (8766) and CR3.

### LUMI-279 — The space store: `SpaceMessage`, `SpaceGist`, the space's vectors, a session per space

**Description:**
A store of the room's own, `state/space_store.py`: a SQLite file `<data root>/spaces.sqlite`, separate from the
relationship store (`store.json` / its SQLite), keyed by the space (`channel`), never by `user_id` — a rollback drops it
whole. Plus the shared embedder behind its own short lock (`core/embedder.py`).

**What needs to be done:**
- Records (ARCHITECTURE §Contracts → Memory records, already documented): `SpaceMessage{channel, session_id, speaker,
  role: "user"|"lili", text, emotion?, intensity?, ts, source_id}` and `SpaceGist{channel, day, text}`, as frozen
  dataclasses in a core module (`core/space.py` or `core/spacestore.py` — the interface), the SQLite implementation in
  `state/space_store.py`.
- **Idempotent by `source_id`** per channel and role: a room line's `source_id` is its Matrix `event_id`; her reply's
  `source_id` is the trigger's `turn_id`. `add_lines` returns `(stored, known)`.
- **Ordered by `ts`, not by arrival** (Q1): `window(channel, n, until_ts?)` → the last `n` lines by `ts` (ties by
  insertion); a late or out-of-order line lands in its place.
- **A session per space:** a line's session is the room's session for **her local day of its `ts`**
  (`agora-YYYY-MM-DD`), opened by its first line; rolled at her local midnight (the injected clock / the line's own
  day) or by size (a code constant, e.g. 1000 lines → `agora-YYYY-MM-DD-2`; no new setting). It never touches his
  `Session`; his `/v1/session/new` never closes it.
- **The space's vectors:** a table of its own (`channel`, `source_id`, `role`, vector blob), `add_vectors` /
  `search_vectors(channel, …)` scoped to the channel (search arrives in v3.2; v3.1 writes). Removal by `source_id` ready
  for v3.3's retract (`remove(channel, source_id, role)` drops the line and its vector).
- **The locked embedder:** `LockedEmbedder(inner)` in `core/embedder.py` — `embed` under one short lock, `dim`
  delegated; the server wraps the core's embedder with it **only when the space is on** (off → byte-identical).
- Atomic writes (SQLite transactions), a corrupt row skipped, never fatal; thread-safe (one connection lock).

**Dependencies:** LUMI-278

**Expected result:**
The room's lines and her replies can be stored, read back in `ts` order and embedded, in a file of their own that never
holds a `user_id`.

**Acceptance criteria:**
- [ ] `SpaceMessage` / `SpaceGist` with the documented fields; the store keyed by `channel`.
- [ ] Idempotent by `source_id` (`stored` / `known`); the window ordered by `ts`; the session per local day, rolled by
  size; his sessions untouched.
- [ ] `LockedEmbedder` serializes `embed`; the core's own path unchanged when the space is off.
- [ ] **Tests:** unit — round-trip, idempotency, `ts` ordering with late lines, the session id at a local midnight
  (fake clock, a DST day), the size roll, vector add/remove by `source_id`, a second channel never seen by the first,
  a corrupt row skipped; `LockedEmbedder` with a `MockEmbedder` from two threads.
- [ ] **Contract:** `tests/contract/test_memory_records.py` pins `SpaceMessage` / `SpaceGist`;
  `tests/contract/test_isolation.py` extended — a space's records never in the `Repository` (no `user_id` anywhere in
  the space store) and his records never in the space store. ARCHITECTURE §Contracts checked against what was built.
- [ ] **Gates:** `ruff`, `pytest`.

### LUMI-280 — The space turn in the core: `observe`, the room's prompt, its own model client and lock

**Description:**
`core/space.py` — the room's logic, interface-independent: hearing (`observe`) and answering (the **space turn**),
with an injected store (LUMI-279), its own `LLMClient`, the locked embedder, the injected clock and the canon text. It
never calls `Core.reply`, never takes the core's or the server's lock and never writes his state.

**What needs to be done:**
- `AgoraSpace(store, llm, *, model, canon, clock, embedder=None, window=40, timeout_s=20)`:
  - `observe(lines) -> (stored, known)` — store new lines in their sessions, embed the new ones (best-effort: an
    embedder failure is logged, the lines stay stored), **no model call**.
  - `turn(speaker, text, turn_id) -> SpaceOutcome{outcome: "reply", reply, emotion, intensity, turn_id, stats}` — the
    trigger stored idempotently under `turn_id` (its `ts` = the observed one if known, else the clock); **a known
    `turn_id` with a stored reply returns that outcome, never a second model call** (R1); the room's prompt; one call
    to its own client (`reply_structured`, no tools); the v0.3 emotion gate (`validate` — unknown → `calm`, clamped);
    her reply stored as `role: "lili"` under the trigger's `turn_id` and embedded.
  - **The room's prompt (v3.1's minimal recipe):** the canon + a short framing (a room with several speakers; answer
    the last line) + the window (the last `window` lines by `ts`, the trigger last) as one quoted transcript block,
    each line «Name: text», her own lines marked as hers. The transcript is **data**, never instructions. Nothing of
    his: no facts, summaries, impressions, recall, closeness, thoughts, plans, needs or mood text (the room rule, the
    mood's resolution, the name guard and the sentinel test are v3.2).
  - **One room turn at a time:** its own lock, taken without blocking → `SpaceBusy` (→ `409`).
  - **Its own timeout:** the room's client is built with `turn_deadline_s = timeout_s` (→ `TurnDeadlineExceeded` →
    `504`), plus a backstop in the caller; a turn past its timeout stores nothing as her line (its reply is dropped
    when it ends).
  - Errors: `LLMError` → `502`; an empty or invalid reply (`EmotionError`) → `500` in v3.1 (silence for the bridge;
    v3.3 turns it into `pass`).
- **The room's own client:** `build_space_llm(cfg)` → a `GeminiClient` with `thinking_off=True`, no tools, its own
  instance (its `last_stats` never mixes with the core's) and the `GEMINI_API_KEY`; enabled without a key or a token
  → a configuration refusal at start (LUMI-281 wires it).
- **Usage:** the space's turns add up in its own totals; at its session's roll or the server's stop one ledger row is
  written with `channel: "agora"` (`UsageRecord` gains an optional `channel`, serialized only when set — his rows stay
  byte for byte). Nothing reaches `Core.totals`.

**Dependencies:** LUMI-279

**Expected result:**
Given lines and a trigger, the space answers with a validated `{reply, emotion, intensity}` from its own fake client,
stores both lines, and leaves every attribute of a `Core` untouched.

**Acceptance criteria:**
- [ ] `observe` idempotent by `id`, no model call (the fake client's call count stays 0), lines embedded.
- [ ] A turn: the prompt holds the canon, the window in `ts` order with the trigger last; the reply validated by the
  gate; both lines stored; a retry with the same `turn_id` returns the stored outcome with no second call.
- [ ] One turn at a time (`SpaceBusy`); the timeout (`TurnDeadlineExceeded` driven by an injected clock) stores no reply.
- [ ] The ledger row carries `channel: "agora"`; an owner row without `channel` is unchanged.
- [ ] **Tests:** unit with a fake `LLMClient` and `MockEmbedder`, an injected clock; malformed replies (unknown
  emotion → `calm`, intensity clamped); a `Core` built beside it keeps its `last_emotion`, `last_stats` and `totals`.
- [ ] **Gates:** `ruff`, `pytest`.

### LUMI-281 — The server: `channel` on the turn, `/v1/observe`, `"agora": 1`, the scoped room token

**Description:**
`server/app.py` and `server/__main__.py`: the agora space API v1 on the server, exactly as `docs/agora-space-api.json`
says, with the space off by default (the routes absent, today's API byte for byte).

**What needs to be done:**
- `TurnRequest` gains `channel` (`"owner"` default | `"agora"`; anything else → `422`), `speaker`, `register` (the
  room's: `"voice"`; ignored on his channel). A turn with no `channel` runs today's path unchanged.
- `POST /v1/turn` with `channel: "agora"` → the space turn (LUMI-280) on its own thread with a backstop wait of
  `timeout_s`: **never** `_Service.begin_turn`, the core lock, `last_input`, the outbox, the event bus or
  `publish_state`. The response is the contract's `{outcome, reply, emotion, intensity, turn_id, stats{model,
  input_tokens, output_tokens, latency_ms}}` — never `thinking`, `state`, `mood`, `intent` or `style`. A room turn
  needs `speaker` and `turn_id`; `images` → `422`. `/v1/turn/stream` with `channel: "agora"` → `422`.
- `POST /v1/observe {channel: "agora", lines: [{id, speaker, text, ts}]}` → `{stored, known}`; at most
  `observe_batch_max` (200) lines → else `422`; a line without `id` → `422`.
- **The speaker rule** (Q3): one line, 1–64 characters, no `:` and no newline → else `422` (on `observe` and on the
  turn). The rule is added to the contract's `observe.about` as a clarification (API still v1) and announced to
  matrix-agora to re-copy (`cmp`).
- `GET /v1/health` gains `"agora": 1` **only while the space is on**.
- **The room's token** (`spaces.agora.token`): reaches `POST /v1/turn` and `POST /v1/observe` with `channel: "agora"`
  only (and `retract` in v3.3); `403` "the room's token reaches only the agora space" on `/v1/state`, `/v1/events`,
  `/v1/command`, `/v1/directive`, `/v1/session/new`, `/v1/turn/stream` and on any other channel. Constant-time compare,
  never logged. The owner's token keeps its full reach (including `channel: "agora"`).
- Status mapping: busy → `409` "Лілі is answering the room — try again"; `LLMError` → `502`; timeout → `504`; a
  malformed request → `422`; anything else → `500` (logged).
- `server/__main__.py`: with the space on, build the store, the room's client, the `LockedEmbedder` around the core's
  embedder, and `AgoraSpace`; refuse to start (exit 78) when the space is on without a room token, with a room token
  equal to the client token, or without a Gemini key; at the stop, close the room's session (its ledger row) beside his.
- Off: `create_app` builds exactly today's routes (the route-set contract unchanged).

**Dependencies:** LUMI-280

**Expected result:**
With the space on, the bridge's calls from the contract work end to end against a fake model; with it off, the API is
today's, byte for byte.

**Acceptance criteria:**
- [ ] The route set with the space off is today's; with it on it adds `POST /v1/observe` only.
- [ ] Health shows `"agora": 1` only when on.
- [ ] The `403` matrix for the room's token (every other route, every other channel); `401` without a token.
- [ ] `409` for a second room turn while one runs; `504` past the timeout (fake slow client, injected clock);
  `502` on `LLMError`; `422` for a bad speaker, a missing `id`, 201 lines, an unknown channel, images in a room turn.
- [ ] **Tests:** unit (`tests/unit/test_server_agora.py`) with a fake model client — no network.
- [ ] **Contract:** `tests/contract/test_server_api_contract.py` — the route set off/on; a new
  `tests/contract/test_agora_server_contract.py` drives the API v1 examples for `health`, `observe` and `turn` through
  the app (fake model returning the example's reply) and checks the responses' shapes and values as written; the
  contract file's speaker clarification pinned by `tests/contract/test_agora_api_contract.py`; ARCHITECTURE §Contracts
