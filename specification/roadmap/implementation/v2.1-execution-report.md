## Fixes applied during execution

- **`uv` checked after the checkout** (rehearsal) — moved before any change (in b2a477f).
- **Per-path overrides beat `LUMI_HOME`** (real migration) — the dev `.env` had `LUMI_FILES_DIR=.lumi/files`
  and `LUMI_JOURNAL_DIR=.lumi/journal`; copied into prod they'd have resolved inside `app/`. Removed from
  the prod `.env`; PROD_SETUP.md now says so (356b634).
- **A running prod under `uv run` went undetected** (real migration) — the child python shows in `ps` as
  the framework `Python.app`, not the venv path; detection now also asks `lsof -d cwd` (4500146).

## Architecture impact

- The **env-key warning** was refined from "every key in `.env.example`" to "keys **new in this release**"
  (the full list is ~200 commented optional settings — noise).
- The guard accepts **any exact tag** (not only `v<VERSION>`), so the first prod install can run on a
  pre-release tag (`v2.1.0-rc1`) before `v2.1.0` exists.

  written but never read back (4 mood calls on 2026-10-04, theme `3am` → `quiet-collapse`).
